Temporal-Pyramid WiFi Sensing Ensemble

Length-aware multi-task RF sensing network that preserves coarse temporal order with global, early, middle, and late attention before equal-weight three-seed ensembling.

INPUT Configured CSI Tensor Standardized amplitude + true packet length
→

TEMPORAL PYRAMID Global + Segment Attention Coarse temporal order is preserved
→
ENSEMBLE OUTPUT Seed Ensemble Equal-weight soft probability average
